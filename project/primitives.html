05 · Textarea

多行输入

给视频写一段为什么收藏。可垂直拉伸，但不允许水平。

支持 Markdown · ⌘+Enter 保存
06 · Select

下拉

原生选择器，皮肤接入系统。复杂选择（多选、搜索）由后续的 Menu / Combobox 承担。

07 · Switch

开关

用于"现在是 / 不是"，不用于提交。状态切换 200ms，落点带轻微滑出。

Default
In context
08 · Checkbox

复选

多选场景、批量操作、表单同意条款。支持 indeterminate（"已选其中一些"）。

09 · Radio

单选

互斥选项。三个以下时用 radio，更多时改用 select。

10 · Tooltip

气泡提示

纯 CSS 实现，hover 350ms 后浮出。永远不替代必要的标签。
